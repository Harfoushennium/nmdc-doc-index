# NMDC Document Index

The owner reviews a proposed index built from project deliverable registers before it becomes the approved index.

## Language

**Source Workbook**:
An original Excel deliverable register containing documents, revisions and events. Source workbooks remain read-only inputs.
_Avoid_: Master index, proposal

**Source Scope**:
The set of whole source workbooks chosen for inclusion in a proposal, subject to the project's documented selection rules.
_Avoid_: Approved rows, flag selection

**Staged Proposal**:
A candidate index awaiting the owner's review and explicit approval. A staged proposal has its own identity and can replace an earlier proposal without changing the approved index.
_Avoid_: Approved update, review draft

**Review Draft**:
The owner's pending source choices, notes and Review Flag inputs associated with a staged proposal. A review draft is separate from both extracted records and saved review decisions.
_Avoid_: Staged proposal, approved data

**Review Decision**:
An owner's recorded outcome, comment or resolution status for a Review Flag. It records the review without changing the underlying extracted document, revision or event.
_Avoid_: Data correction, partial approval

**Approved Index**:
The index resulting from the owner's last successful approval of a staged proposal. A later scan or review draft does not replace it.
_Avoid_: Pending update, review draft
