# RC1 owner acceptance

This candidate is not production approved. Keep V1 and Candidate 09 available. Use the identical ZIP and SHA256 on both PCs. Do not overwrite a legacy workspace or use its sole copy for testing. No Python, Node, Git, Office installation, administrator rights or network access is required to run the application. An existing browser is required. Excel is required for the physical Excel acceptance cases.

1. Extract the entire ZIP into a new local folder. Verify the ZIP SHA256 against the supplied checksum. Run `Run-UAT.ps1 -MachineRole work` or `-MachineRole home`. It verifies every package file and launches an isolated workspace. It records no case as passed automatically. If organization policy blocks the script, do not bypass it: verify the manifest using approved local tools and launch `Launch.exe --workspace "a new isolated folder"`.
2. Record the OS, Excel version, package hash and build in the generated local evidence folder. Disconnect external networking for the offline test. Select a separately backed-up DATA copy in Sources & jobs. Scan, cancel, retry and reconnect. Verify selected/newest/excluded files and immutable source hashes. Confirm no proposal is automatically approved.
3. In File review & flags inspect changed records, before/after and worksheet/row evidence. Save notes and choices, reload and restart. Check unsaved and stale-tab actions are refused. Hold and Reject preserve approved data. Test accepted/deferred new, changed and intentional removal cases on disposable fixtures. Historical drafts remain available.
4. Save/reopen/revert rules, project mappings, source exclusions and custom fields. Review compatibility errors explicitly. Search Events/Documents/Revisions with exact, AND and exclusion syntax, selected columns, reset, filters, groups, pages and saved views. Verify typing focus and theme/density/profile persistence after restart. Reconcile dashboard totals to exported identities.
5. Export full history, empty and filtered scopes. A hyperlink-capacity split needs explicit consent; each part has one INDEX sheet/table. Retain the exception report and original literal targets. Open every XLSX in actual Excel: no repair prompt/macros, leading zeros and dates correct, row/key/type totals reconcile. Click a known safe document and source-workbook hyperlink on each PC. Record available/unavailable targets separately; structural checks do not prove a click succeeded.
6. In Settings preview a copy of the legacy package, inspect every blocker and compatibility item, then confirm side-by-side import into a new workspace only. Launch that workspace separately and reconcile exact approved/pending IDs, choices, drafts, flags, notes, settings and history. Legacy hashes must remain unchanged. Exercise backup, isolated restore, undo, reset/empty/rescan, upgrade and rollback on disposable workspaces. Keep required recovery bundles.
7. Repeat the measurement plan in the release contract: three fresh process/workspace trials plus five warm trials and at least 30 representative queries; record complete startup/scan/approval/undo/export times, memory/disk and sync effects. Required local ceilings: startup 5s, full median 15s, unchanged median 3s, query p95 500ms, 40,494-event export median 10s. Changed-source and approval ceilings still require the owner's measured-baseline decision. Never mark a missed ceiling as passed.
8. Complete all 46 rows in `results.csv`: PASS/FAIL/BLOCKED/NOT RUN, expected/actual, evidence path and finding ID. Keep project records/screenshots/logs local and share sanitized aggregate evidence only. Explicitly record legacy-ticket supersession decisions. Work and home evidence, independent QA and all required case results must be reconciled before readiness for production approval. No production merge or cutover is authorized by this test.

Troubleshooting: an unavailable/locked source requires restoration and rescan, never approval of apparent deletion. A stale version requires reload and review. A migration blocker requires source/configuration reconciliation; do not alter the legacy baseline to force import. An existing workspace cannot be an import/restore destination. If the app reports another writer, close that workspace's existing app using Exit. Never terminate unrelated Excel or application processes.
