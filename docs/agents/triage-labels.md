# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation needed |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Specified and suitable for agent implementation |
| `ready-for-human` | `ready-for-human` | Human implementation required |
| `wontfix` | `wontfix` | Will not be actioned |

These are configured names, not a claim that the labels already exist remotely. Installation creates no GitHub labels. When an authorized triage task needs a missing label, report it or create it only within that task's authorization. A readiness label does not grant approval to expand NMDC scope or merge a PR.
